# Исходный код проекта

В этой папке находится исходный код практической работы по теме «Разработка системы управления салоном красоты».

## Состав проекта

- `Reliability.csproj` — настройки проекта C#.
- `Program.cs` — запуск программы и проверка сценариев записи.
- `SalonBooking.cs` — класс записи клиента и проверка данных.
- `BookingService.cs` — обработка ошибок.

## Назначение

Программа демонстрирует проверку данных записи клиента, обработку ситуаций, когда услуга недоступна или время занято, а также запись событий в журнал.
