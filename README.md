# salon-krasoty
# Разработка системы управления салоном красоты

## Описание проекта

Проект посвящён разработке системы управления салоном красоты. В практической работе рассматривается обработка записей клиентов, проверка введённых данных, обработка ошибок и ведение журнала событий.

## Структура проекта

- `src/Reliability.csproj` — файл настроек проекта.
- `src/Program.cs` — запуск программы и проверка сценариев.
- `src/SalonBooking.cs` — модель записи клиента.
- `src/BookingService.cs` — обработка ошибок и журналирование.
- `src/README.md` — описание исходного кода.

## Проверяемые сценарии

1. Выбранная услуга недоступна.
2. Выбранное время уже занято.
3. Запись клиента оформляется успешно.
